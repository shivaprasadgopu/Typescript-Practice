# TypeScript Practice

This repository is dedicated to practicing TypeScript. Here, you will find various exercises and examples that showcase TypeScript's features and capabilities.

## Objectives
- Understand the basics of TypeScript.
- Explore advanced TypeScript concepts.
- Build small projects to enhance coding skills.

## Getting Started
1. Clone the repository.
2. Install TypeScript globally with `npm install -g typescript`.
3. Compile TypeScript files using `tsc` command.
4. Run the JavaScript output in Node.js or a browser.
